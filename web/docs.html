Documentación de Rivo

Rivo es un lenguaje de propósito general con sintaxis estilo Python y Godot (GDScript), pero compilado en vez de interpretado. Tiene tipos explícitos, bloques por indentación y un compilador en C con backend LLVM. Esta guía describe el diseño aprobado y marca con cuidado lo que ya está comprobado.

01 Empezar

Requisitos

  • Un compilador de C compatible con C11 (GCC o Clang).
  • CMake 3.16 o posterior.
  • LLVM con sus archivos de desarrollo.
  • clang, que el compilador usa para enlazar los programas generados.

Compilar el compilador

cmake -S . -B build
cmake --build build
./build/rivo --help
./build/rivo --version

Instalación

make install instala Rivo en tu directorio de usuario (por defecto ~/.local, sin permisos especiales). El binario encuentra su biblioteca estándar y su runtime por su propia ubicación, sin variables de entorno: 

make install
rivo --help
make install PREFIX=/otro/dir
make uninstall

Instala ~/.local/bin/rivo (compilador), ~/.local/share/rivo/lib (biblioteca estándar .ro) y ~/.local/lib/librivo_runtime.a (runtime para enlazar). En el árbol de desarrollo el binario sigue llamándose build/rivo.

02 Tu primer programa

Crea hola.ro:

fn main():
    print("Hola, mundo")

Compílalo y ejecútalo:

./build/rivo hola.ro
./hola

fn main() es el punto de entrada. El cuerpo está indentado; no se escriben llaves. También puedes elegir el ejecutable de salida: 

./build/rivo hola.ro -o saludo
./saludo

Un programa un poco más completo:

fn doble(numero:int) -> int:
    return numero * 2

fn main():
    var valor:int = 21
    print(doble(valor))

El tipo de cada variable y parámetro se escribe explícitamente. Rivo no infiere el tipo de una declaración.

Un programa con la forma típica de Rivo: funciones cortas, nombres claros y control de flujo que se lee de arriba abajo:

fn es_mayor(edad:int) -> bool:
    return edad >= 18

fn main():
    var edad:int = 20

    if es_mayor(edad):
        print("Acceso concedido")
    else:
        print("Acceso denegado")

    var nombres:list<string> = ["Ana", "Luis", "Roi"]

    for nombre in nombres:
        print(f"Bienvenido {nombre}")

03 Sintaxis e indentación

Bloques

Los bloques empiezan después de : y se delimitan con indentación: 

if edad >= 18:
    print("Adulto")
else:
    print("Menor")

No se usan {} para bloques ni existe elif/elseif. Mantén la misma indentación dentro de cada bloque. Una línea nueva termina una sentencia: las expresiones y llamadas no continúan en la línea siguiente.

pass es la sentencia vacía reservada, útil para dejar provisionalmente un bloque sin acciones: 

fn pendiente():
    pass

La indentación no es decorado: es la gramática. Un bloque anidado se lee como un esquema, igual que el pseudocódigo: 

fn clasificar(nota:int) -> string:
    if nota >= 90:
        return "sobresaliente"
    else:
        if nota >= 70:
            return "notable"
        else:
            if nota >= 50:
                return "suficiente"
            else:
                return "insuficiente"

Comentarios

Un comentario de una línea empieza por #:

# Calcular el total
var total:int = 12

Un comentario de varias líneas empieza con #! y termina en el primer !#. No se anida y un bloque sin cerrar es un error de sintaxis. // no inicia un comentario: 

#!
Este bloque es un comentario.
No se anida.
!#

Visibilidad

Un identificador que empieza por _ es privado; los demás son públicos. La regla se aplica a funciones, variables, constantes y parámetros. Los módulos solo exponen funciones públicas al importador. 

fn _auxiliar(valor:int) -> int:
    return valor + 1

04 Variables, constantes y tipos

La forma de una variable es var nombre:tipo = valor; una constante usa const: 

fn main():
    var edad:int = 20
    edad = 21

    const PI:float = 3.14159

Las variables pueden reasignarse y las constantes no. No hay conversión implícita al asignar: un valor int no se convierte automáticamente a float.

Ámbito global: var y const se declaran dentro de funciones (también en módulos). A nivel global el compilador reporta un error: no existen variables globales.

Tipos oficiales

TipoUso
intNúmero entero.
floatNúmero con parte fraccionaria.
stringTexto; se concatena con +.
boolValor true o false.
charUn carácter entre comillas simples, por ejemplo 'A'.
list<T>Lista cuyos elementos tienen el tipo T, por ejemplo list<int>.
map<K, V>Mapa de claves K a valores V, por ejemplo map<string, int>.
nullValor y tipo especial del lenguaje.

No forman parte del lenguaje los tipos void ni any. Una función sin tipo de retorno explícito no devuelve un valor; eso no añade un tipo void al lenguaje.

Los ocho tipos oficiales, declarados de forma explícita:

fn main():
    var entero:int = 42
    var flotante:float = 3.14
    var texto:string = "Rivo"
    var flag:bool = true
    var letra:char = 'R'
    var nada:null = null
    var lista:list<int> = [1, 2, 3]
    var tabla:map<string, int> = ["uno": 1]

    print(f"{entero} {flotante} {texto} {flag} {letra}")
    print(lista.len())
    print(tabla["uno"])

05 Operadores y expresiones

Precedencia (de menor a mayor)

  1. Asignación: =, +=, -=, *=, /=.
  2. or
  3. and
  4. Comparaciones: ==, !=, >, <, >=, <=.
  5. Suma y resta: +, -.
  6. Multiplicación, división y resto: *, /, %.
  7. Operadores unarios: -valor, not.

Por ejemplo, a + b * c equivale a a + (b * c).

Aritmética y división

La división entre dos enteros produce un entero truncado hacia cero. Si al menos un operando es float, el resultado es float: 

fn main():
    var mitad:int = 7 / 2
    var mitad_float:float = 7.0 / 2
    # var invalido:float = 7 / 2   # error de tipo

lista + otra_lista crea una lista nueva sin modificar las originales (exige el mismo tipo de elemento). Los mapas no admiten +.

Comparaciones

== y != comparan el contenido de las cadenas (strcmp). No se admiten comparaciones de orden entre cadenas, ni igualdad entre listas o mapas.

Asignación y comparación

fn main():
    var puntos:int = 3
    puntos = 4

    if puntos == 4:
        print("Cuatro")

Precedencia y operadores compuestos en un solo vistazo:

fn main():
    var a:int = 2 + 3 * 4        # 14: multiplica antes
    var b:int = (2 + 3) * 4      # 20: los paréntesis mandan

    var cuenta:int = 10
    cuenta -= 3                  # 7
    cuenta *= 2                  # 14

    var resto:int = 17 % 5       # 2
    var activo:bool = true and not false

    print(f"{a} {b} {cuenta} {resto} {activo}")

06 Funciones

Las funciones se declaran con fn, parámetros tipados y un tipo de retorno opcional: 

fn sumar(a:int, b:int) -> int:
    return a + b

fn saludar(nombre:string):
    print("Hola " + nombre)
  • return con un valor debe coincidir con el tipo declarado.
  • Un nombre que empieza por _ declara una función privada.
  • main solo puede existir en el archivo principal, no en un módulo importado.
  • Los programas correctos terminan con código de salida cero salvo que fallen.

Funciones privadas como utilidades internas: se usan dentro del mismo archivo y no forman parte de la interfaz del módulo. 

fn _normalizar(texto:string) -> string:
    return lower(trim(texto))

fn presentar(nombre:string):
    print("Hola, " + _normalizar(nombre))

fn main():
    presentar("  AMINE  ")
    presentar("  rivo  ")

07 Control de flujo

Condicionales

if temperatura > 30:
    print("Hace calor")
else:
    print("Temperatura moderada")

Las condiciones usan bool; se combinan con and, or y not. No existe elif: para más ramas se anida otro if dentro del else.

while

fn main():
    var contador:int = 0
    while contador < 3:
        print(contador)
        contador += 1

break y continue hacen el bucle legible sin rodeos:

fn main():
    var intentos:int = 0

    while true:
        intentos += 1

        if intentos == 2:
            continue          # se salta la iteración 2

        if intentos > 4:
            break             # termina el bucle

        print(f"intento {intentos}")

for

La forma es for variable in iterable::

for nombre in nombres:
    print(nombre)

Con range y condiciones, un bucle se lee como una receta:

fn main():
    for i in range(0, 4):
        if i % 2 == 0:
            print(f"{i} es par")
        else:
            print(f"{i} es impar")

break termina el bucle y continue pasa a la siguiente iteración; ambos solo son válidos dentro de un bucle.

try y catch

try:
    var valor:int = numeros[10]
    print(valor)
catch error:
    print("Fallo: " + error)

Reglas: try exige exactamente un catch. catch nombre declara nombre como string con el mensaje del fallo. Se capturan los abortos de runtime (índice fuera de rango, clave de map inexistente, fichero inexistente, rangos inválidos, fallos de memoria). return, break y continue están prohibidos dentro de try. No existe throw.

08 Cadenas y f-strings

Las cadenas se escriben con comillas dobles y admiten estos escapes:

EscapeSignificado
\nNueva línea
\rRetorno de carro
\tTabulador
\0Carácter nulo
\\Barra invertida
\"Comilla doble
\'Comilla simple

Los escapes desconocidos se conservan como barra y carácter. La concatenación usa + o concat(a, b). Las cadenas viven en memoria gestionada por el runtime: el programa no las libera manualmente.

F-strings

Un prefijo f permite interpolar valores dentro de {}:

fn main():
    var nombre:string = "Ana"
    var edad:int = 20
    print(f"Hola {nombre}, tienes {edad} años")

Escapes y f-strings con funciones e índices dentro de las llaves:

fn main():
    var ruta:string = "docs\\web"
    print("primera\tcolumna\nsegunda")

    var nombre:string = "rivo"
    print(f"{upper(nombre)} tiene {len(nombre)} letras")
  • {{ y }} producen llaves literales.
  • Dentro de las llaves se admite una primaria con sufijos (llamada, miembro, índice), pero no operadores: f"{a + b}" es error de sintaxis.
  • Solo se interpolan int, float, string, bool y char. Interpolar listas, mapas o null es error semántico.
  • El resultado de un f-string siempre es string.

09 Listas y mapas

Listas

fn main():
    var numeros:list<int> = [1, 2, 3]
    var primero:int = numeros[0]
    numeros[0] = 10
    numeros.add(4)

Listas que se leen como una lista de la compra:

fn main():
    var compra:list<string> = ["pan", "leche"]
    compra.add("huevos")

    for producto in compra:
        print("- " + producto)

    compra.remove("leche")
    print(f"quedan {len(compra)} productos")

El diseño contempla add, remove, len() e indexación. Leer o escribir un índice fuera de rango termina el programa con un error de runtime (capturable con try/catch). La concatenación lista + otra exige el mismo tipo de elemento.

Mapas

fn main():
    var edades:map<string, int> = [
        "Ana": 20,
        "Luis": 25
    ]

    edades["Ana"] = 21
    edades["Pedro"] = 30

Los mapas no usan llaves: se escriben con corchetes y pares clave: valor. Consultar una clave inexistente es un error de runtime. Los mapas no admiten + ni comparación con ==/!=.

10 Imports y módulos

Un módulo es un archivo .ro compilado en la misma unidad:

import matematicas
import matematicas as math
from matematicas import absoluto

fn main():
    print(math.pi())
    print(absoluto(-4))

Combinando módulos, el programa sigue leyéndose en español:

import texto
from matematicas import absoluto

fn main():
    var saludo:string = "  hola rivo  "
    print(texto.limpiar(saludo))
    print(absoluto(-7))
    print(texto.mayusculas("limpio"))
  • from modulo import funcion permite llamar funcion(...).
  • import modulo as alias permite llamar alias.funcion(...).
  • Los imports solo se permiten a nivel global, nunca dentro de funciones o bloques.
  • Solo se pueden usar funciones públicas; los imports circulares y los nombres duplicados son errores.

Búsqueda de módulos

Para un módulo matematicas, el compilador busca matematicas.ro en este orden:

  1. El directorio del archivo principal.
  2. Los directorios indicados con -I, en el orden de la CLI.
  3. El directorio indicado por RIVO_LIB, si está definido.
  4. La biblioteca estándar que acompaña al compilador.
./build/rivo programa.ro -I ./modulos

11 Funciones incorporadas

Estas funciones existen sin importar nada. Las firmas las comparten el análisis semántico y el codegen.

CategoríaFunciones
Consola print, input, clear, move, sleep_ms, read_key
Texto concat, split, join, upper, lower, trim, substring, replace, contains, starts_with, ends_with, find, len
Conversión str, ord, chr, to_int, to_float, bin, oct, hex, round, pow, abs
Aleatoriedad y tiempo random, random_float, seed, time_ms, epoch_ms
Listas range, divmod, sorted, reversed, all, any
Ficheros read_file, write_file, file_exists

Un programa cotidiano con builtins de texto, listas y conversión:

fn main():
    var datos:string = "ana,luis,roi"
    var partes:list<string> = split(datos, ",")

    for p in partes:
        print("- " + upper(p))

    var edad:string = "42"
    print(f"el año que viene tendrás {to_int(edad) + 1}")

Reglas comunes: los fallos de ejecución (fichero inexistente, random con min > max, substring fuera de rango, índice o clave inexistente) abortan el programa con exit distinto de cero, salvo que estén dentro de un try. Los strings devueltos viven en la arena del runtime y no se liberan.

Los módulos viven en lib/ y usan nombres en español. El espacio de nombres es plano: los nombres no pueden chocar entre módulos ni con tu programa.

La stdlib también se lee en español; aquí, media y desviación de un listado de notas:

    var notas:list<float> = [8.5, 6.0, 9.5]
    print(estadistica.media(notas))
    print(estadistica.desviacion_estandar(notas))

13 Funciones externas en C

La sentencia external declara una función implementada en un fichero C que el compilador compila y enlaza contigo: 

external "utilidades.c" fn doble_c(a:int) -> int

fn main():
    print(doble_c(21))

Y el fichero utilidades.c que lo implementa (el compilador lo compila y enlaza por ti):

/* utilidades.c */
int doble_c(int a) {
    return a * 2;
}
  • external no lleva cuerpo: es una declaración a nivel global.
  • Parámetros y retorno admitidos: int, float, string, bool, char (o sin retorno). No se pueden pasar listas ni maps por FFI.
  • La ruta del fichero C es relativa al fichero .ro que la declara, o absoluta.
  • Los strings que devuelva el código C deben ser estáticos: Rivo no los copia.
  • En Linux el enlace añade -lm.

14 Errores y diagnósticos

Rivo distingue errores de compilación (léxicos, sintácticos, semánticos y de codegen) de los errores de ejecución, que el runtime aborta o captura en un catch.

Cada error se imprime bajo una clase conocida de Python:

ClaseCuándo
SyntaxErrorLéxico, sintaxis, break/continue/return fuera de sitio.
TypeErrorTipos, argumentos, retorno, índices, asignación.
NameErrorNombres no definidos o duplicados, funciones, no inicializadas.
ValueErrorAsignación a constante; conversiones inválidas en runtime.
AttributeErrorAcceso a miembros privados.
ImportErrorMódulos e imports.
IndexError, KeyErrorRuntime: índice de lista o clave de map.
FileNotFoundError, MemoryError, RuntimeErrorRuntime: ficheros, memoria e iteración inválida.
SystemErrorCodegen, internos y LLVM.

Un diagnóstico muestra archivo, línea, columna, código fuente, marcador ^, detalle y sugerencia:

NameError: funcion no encontrada
  --> programa.ro:2:1
   |
 2 | printt("x")
   | ^^^^^^
   |
   = sugerencia: quizas quisiste decir 'print'

Otro ejemplo, esta vez de tipos: el error apunta exactamente al valor que no encaja.

TypeError: tipo incompatible en la asignacion
  --> cuenta.ro:3:24
   |
 3 |     var texto:string = 42
   |                        ^^
   |
   = detalle: se esperaba string y se encontro int

Cuando stderr es una terminal (y no hay NO_COLOR), la cabecera y los marcadores se emiten con colores ANSI. En fichero o pipe: texto plano.

15 CLI del compilador

El compilador se llama rivo:

rivo programa.ro            # genera el ejecutable "programa"
rivo programa.ro -o salida  # elige la salida
OpciónEfecto
-o archivoNombre del ejecutable de salida.
-cSolo genera el objeto.
-SSolo genera ensamblador.
-emit-irEmite el LLVM IR.
-gInformación de depuración.
-O0 … -O2Nivel de optimización.
-I dir / -IdirDirectorios extra para buscar módulos (repetible).
-v, --verboseSalida detallada y tiempos por fase.
--keep-objectConserva el fichero objeto.

Proyectos con rivo.toml

Si el directorio (o uno superior) lleva un manifiesto rivo.toml, el compilador lo detecta solo: declara el nombre, la versión, la entrada, el binario, las rutas de [dependencias] y las opciones por defecto de [compilador]. Con manifiesto:

  • Los artefactos van a target/debug/ o target/release/.
  • La compilación muestra un estado estilo Cargo con colores (Compilando … Finished …), respetando NO_COLOR.
  • Una caché por fecha evita recompilar si nada cambió (Finished debug (sin cambios)).
  • rivo sin argumentos usa la entrada del manifiesto.
[proyecto]
nombre = "miapp"
version = "0.1.0"
entrada = "src/main.ro"

[dependencias]
utilidades = "libs"

[compilador]
perfil = "release"

16 Arquitectura del compilador

El compilador sigue un pipeline lineal, escrito en C:

código fuente
    ↓
lexer        → tokens (INDENT, DEDENT, NEWLINE…)
    ↓
parser       → AST
    ↓
análisis semántico  → tabla de símbolos, tipos, visibilidad
    ↓
LLVM IR      → verificación y optimización
    ↓
archivo objeto
    ↓
linker (clang)
    ↓
ejecutable

La regla del proyecto es inequívoca: el programa se valida antes de generar código. La implementación LLVM se adapta al diseño del lenguaje, nunca al revés.

17 Estado del proyecto

Diseñado ≠ implementado. Rivo está en fase de construcción del compilador. Que una característica aparezca en esta guía significa que está diseñada; no garantiza que todas sus combinaciones estén probadas.

Comprobado con pruebas de extremo a extremo y del runtime:

  • Variables, constantes, funciones y visibilidad con _.
  • if/else, while, for, break y continue.
  • Listas, maps, operadores y f-strings.
  • Imports, módulos y funciones externas en C.
  • try/catch sobre los aborts de runtime.
  • Biblioteca estándar y funciones incorporadas.
  • Manifiesto rivo.toml: dependencias, entrada, target/ con perfiles y caché, y --run.

Ejecuta las suites antes de depender de cualquier cambio:

sh tests/run_tests.sh
sh tests/runtime/run_tests.sh

18 Referencia rápida

fn sumar(a:int, b:int) -> int:
    return a + b

fn main():
    const LIMITE:int = 3
    var contador:int = 0
    while contador < LIMITE:
        print(f"vuelta {contador}: {sumar(contador, 1)}")
        contador += 1
  • Los bloques usan indentación y :; no usan llaves.
  • Declara tipos explícitamente: var nombre:tipo = valor.
  • Usa == para comparar y = para asignar.
  • if admite else y elif encadenados.
  • Los bucles son while y for; break y continue requieren un bucle.
  • Los mapas y listas usan corchetes; {} solo aparece dentro de f-strings.
  • No se convierten tipos implícitamente.
  • Archivos .ro · binario rivo · backend LLVM.

Una receta completa que junta funciones, listas, condicionales y f-strings:

fn promedio(notas:list<int>) -> int:
    var suma:int = 0
    for n in notas:
        suma += n
    return suma / len(notas)

fn main():
    var nombre:string = "Ana"
    var notas:list<int> = [8, 6, 9]
    var nota:int = promedio(notas)

    if nota >= 5:
        print(f"{nombre}: aprobado con {nota}")
    else:
        print(f"{nombre}: suspenso")
