Rivo es un lenguaje de propósito general con sintaxis estilo Python y Godot (GDScript): bloques por indentación, sin llaves y con tipado estático obligatorio. La diferencia está en la ejecución: se compila a binario nativo con LLVM, no se interpreta.

Filosofía

Estilo Python y Godot, sin llaves

Rivo prioriza la corrección, la coherencia y los diagnósticos claros sobre la cantidad de características. La simplicidad es una decisión, no una carencia.

Sintaxis

Indentación, no llaves

Los bloques se abren con : y se delimitan con indentación. Sin {}, sin ; y sin ruido: el código se parece al pseudocódigo.

Tipos

Estático y explícito

Cada variable declara su tipo: var edad:int = 20. Sin inferencia implícita ni conversiones silenciosas — lo que escribes es lo que el compilador comprueba.

Diagnósticos

Errores con estilo Python

NameError, TypeError, SyntaxError… con archivo, línea, columna, código fuente, detalle y sugerencia. Diseñados para leerse, no para decodificarse.

Biblioteca

Stdlib en español

matematicas, texto, fecha, json, csv, estadistica y más, con nombres en español y funciones incorporadas en inglés.

Ejecución

Binarios nativos

El compilador genera LLVM IR, lo verifica, lo optimiza y enlaza con clang. El resultado es un ejecutable nativo para tu plataforma, sin intérprete.

FFI

Integración con C

La sentencia external declara funciones de ficheros C directamente desde Rivo y el compilador las compila y enlaza contigo.

En la práctica

Así se ve un programa

Funciones con fn, retorno con -> tipo, condicionales sin elif, bucles while y for, listas y mapas con corchetes y f-strings con interpolación {}. 

fn clasificar(edad:int) -> string:
    if edad >= 18:
        return "adulto"
    else:
        return "menor"

fn main():
    var nombres:list<string> = ["Ana", "Luis", "Rivo"]

    for nombre in nombres:
        print(f"{nombre}: {clasificar(18)}")

    var edades:map<string, int> = [
        "Ana": 20,
        "Luis": 25
    ]
    print(edades["Ana"])
  • Los tipos genéricos se escriben list<T> y map<K, V>.
  • Los mapas no usan llaves: se escriben con corchetes y clave: valor.
  • == compara, = asigna; nunca se confunden.
  • Un identificador que empieza por _ es privado.
  • Los errores de ejecución se capturan con try y catch.

Empezar

De cero a tu primer binario

Necesitas un compilador de C (GCC o Clang), CMake 3.16+, LLVM con sus headers de desarrollo y clang para enlazar.

  1. Compila el compilador

    Desde la raíz del proyecto:

    cmake -S . -B build
cmake --build build
./build/rivo --help
  2. Escribe tu programa

    Crea un fichero hola.ro:

    fn main():
    print("Hola, mundo")
  3. Compila y ejecuta

    Rivo genera un ejecutable nativo junto a tu código:

    ./build/rivo hola.ro -o hola
./hola
  4. Instálalo en tu equipo

    Opciones de la CLI: -o, -c, -S, -emit-ir, -g, -O0…-O2, -I dir, --run, --version y --help.

    Con un manifiesto rivo.toml, los artefactos van a target/debug/ o target/release/, hay caché por fecha y rivo --run compila y ejecuta en una pasada (estilo Cargo).

Guías

Vienes de otro lenguaje

Si ya programas en Python, Godot, C o C++, empieza por aquí: equivalencias reales, diferencias importantes y advertencias honestas.

Guía

Rivo para programadores de Python

def → fn, anotaciones obligatorias, listas y diccionarios tipados, f-strings, y las trampas de la división entera y la ausencia de elif.

Guía

Rivo y Godot

GDScript y Rivo comparten la indentación y el espíritu legible. Qué se parece, qué cambia y qué no existe todavía (sin humo): hoy no hay plugin oficial de Godot.

Guía

De C a Rivo

Mismo destino compilado, distinta filosofía: sin punteros ni malloc, con listas, maps, strings gestionados y FFI con external para tu código C existente.

Guía

De C++ a Rivo

vector → list, cout → print, sin plantillas ni clases. Qué gana tu lógica y qué conviene dejar en C++.

Estado del proyecto

En construcción, sin adornos

Rivo se desarrolla en público. Que una sintaxis esté documentada no garantiza que todas sus combinaciones estén implementadas.

Diseñado ≠ implementado. La documentación distingue con cuidado lo aprobado en el diseño de lo comprobado con pruebas. Antes de depender de cualquier característica, ejecuta las suites del proyecto: sh tests/run_tests.sh y sh tests/runtime/run_tests.sh.

  • Compilador completo: lexer, parser, semántica, LLVM IR, objeto y linker.
  • Biblioteca estándar en español: matemáticas, texto, fecha, json, csv, sistema…
  • Funciones incorporadas: texto, listas, ficheros, tiempo, aleatoriedad y consola.
  • Sistema de errores estilo Python con sugerencias y colores en terminal.
  • Integración con C mediante external y enlace con clang.
