Rivo y Godot

GDScript y Rivo comparten la misma alma: indentación, tipado suave o explícito y una sintaxis pensada para leerse. Pero son mundos distintos: Godot es un motor de juegos con su propio ecosistema y Rivo es un lenguaje de propósito general que compila a binarios nativos.

Sin humo: hoy no existe un plugin oficial de Godot para Rivo, ni una API de escenas, nodos o señales. Rivo no se adjunta a un árbol de escenas. Esta guía explica qué se parece y qué podrías hacer hoy, sin prometer integraciones que no hay.

Comparación

GDScript y Rivo, en la práctica

GDScript (Godot)

var puntos: int = 0

func tomar_dano(danio: int) -> void:
    puntos -= danio
    if puntos <= 0:
        morir()
    elif puntos < 30:
        avisar()
    else:
        pass

func _ready() -> void:
    tomar_dano(10)

Rivo

fn tomar_dano(puntos:int, danio:int) -> int:
    var restantes:int = puntos - danio
    if restantes <= 0:
        print("murió")
    else:
        if restantes < 30:
            print("herido")
        else:
            pass
    return restantes

fn main():
    var vida:int = 100
    vida = tomar_dano(vida, 10)
    print(vida)

Nota cómo GDScript admite inferencia (var puntos = 0 es válido) mientras que Rivo exige el tipo; el elif es igual en ambos.

Qué se parecen de verdad

El mismo espíritu de diseño

Indentación

Bloques sin llaves

Tanto GDScript como Rivo delimitan los bloques con indentación y dos puntos. El código se lee como pseudocódigo.

Tipos

Anotaciones con :

GDScript escribe var x: int y Rivo var x:int. La diferencia: en Rivo la anotación es obligatoria y no hay inferencia.

Legibilidad

Palabras clave en inglés, claridad primero

Ambos usan if, else, while, for, in, return, break, continue y pass.

Errores

Fallos visibles

GDScript avisa en el editor y detiene la ejecución; Rivo aborta con clases tipo IndexError o KeyError, o las captura en try/catch.

Ejecución

Intérprete vs. binario

Godot ejecuta GDScript dentro del motor. Rivo compila con LLVM a un ejecutable nativo: no hay motor, no hay runtime de escenas.

Tipado

Opcional vs. obligatorio

GDScript permite omitir tipos; Rivo los exige en cada var, const y parámetro. La corrección se traslada al momento de compilar.

Entonces, ¿qué uso?

Para qué sirve cada uno hoy

Si quieres…Usa
Hacer un juego con escenas, nodos, física o 2D/3D Godot + GDScript (o C#). Rivo no tiene motor.
Aprender programación con una sintaxis clara y tipada, en un binario nativo Rivo.
Escribir herramientas de línea de comandos o utilidades del sistema Rivo (ficheros, sistema, fechas, csv, json… en la stdlib).
Conectar lógica propia con C existente Rivo mediante external.
Scriptear un árbol de escenas en tiempo real GDScript. Hoy no hay puente oficial con Rivo.

¿Y una integración futura? Rivo ya compila a binarios nativos y puede exponer funciones a C (external y fn sin retorno). Esa es la dirección natural si algún día se quisiera un puente con motores externos, pero no hay nada implementado ni aprobado: no lo des por hecho.
