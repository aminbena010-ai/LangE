Guía de conversión

De C a Rivo

Ambos se compilan a binario nativo con LLVM, pero parten de filosofías opuestas: C te da control total y memoria manual; Rivo te da un lenguaje de alto nivel con memoria gestionada, listas, maps, strings seguros y errores en tiempo de compilación.

Ver la documentación completa

La traducción mental rápida: en C tú diseñas la memoria; en Rivo tú describes la lógica. Los punteros, malloc y los arrays de tamaño fijo desaparecen; aparecen list<T>, map<K, V>, string gestionado y try/catch.

Lado a lado

El mismo programa en ambos lenguajes

C

#include <stdio.h>

int doble(int n) {
    return n * 2;
}

int main(void) {
    int edad = 20;
    printf("Hola, tienes %d años\n", edad);
    printf("%d\n", doble(edad));
    return 0;
}

Rivo

fn doble(n:int) -> int:
    return n * 2

fn main():
    var edad:int = 20
    print(f"Hola, tienes {edad} años")
    print(doble(edad))

Sin #include, sin printf con formatos, sin return 0 implícito que perseguir: fn main() es el punto de entrada y print es una función incorporada.

C (bucle sobre array)

int numeros[3] = {1, 2, 3};

for (int i = 0; i < 3; i++) {
    printf("%d\n", numeros[i]);
}

Rivo (bucle sobre lista)

var numeros:list<int> = [1, 2, 3]

for n in numeros:
    print(n)

Diferencias importantes

Lo que C hace y Rivo no

Memoria

Sin punteros ni malloc

No hay punteros, referencias, free ni fugas posibles. El runtime gestiona strings, listas y maps en arenas propias.

Tipos

Ocho tipos, nada más

Solo int, float, string, bool, char, list<T>, map<K, V> y null. Sin unsigned, sin int8_t, sin size_t, sin union.

Preprocesador

Sin #include ni macros

No hay preprocesador: los módulos se importan con import y las constantes con const. Tampoco hay goto ni switch.

Compilación

Mismo destino, distinto camino

C y Rivo terminan en un binario nativo (Rivo pasa por LLVM IR y enlaza con clang), pero Rivo valida tipos y nombres antes de generar código.

Errores

Fallos claros, no segmentaciones

Un índice fuera de rango o una clave inexistente abortan con IndexError/KeyError legibles, o se capturan con try/catch.

FFI

Tu código C sigue sirviendo

Con external puedes seguir aprovechando bibliotecas y funciones C existentes desde Rivo, sin reescribirlas.

Traducción útil

Del día a día de C a Rivo

TareaEn CEn Rivo
Longitud de una lista sizeof(a) / sizeof(a[0]) len(a)
Concatenar texto strcat / snprintf a + b o concat(a, b)
Comparar texto strcmp(a, b) == 0 a == b
Leer un fichero entero fopen + fread + cierre read_file(ruta)
Escribir un fichero fopen + fprintf + fclose write_file(ruta, texto)

Dormir 200 ms usleep(200000) sleep_ms(200)
Número aleatorio rand() % (max - min + 1) + min random(min, max)

Regla de oro al traducir: si en C estás pensando en memoria, tamaño o índices manuales, para y pregúntate si Rivo ya lo resuelve con una lista, un map o un builtin. Casi siempre la respuesta es sí.
