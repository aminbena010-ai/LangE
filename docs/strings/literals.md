# Literales de texto

Escribe strings entre comillas dobles y caracteres entre comillas simples.
Las cadenas no se escriben en varias líneas literales.

```rivo
fn main():
    var mensaje:string = "Hola"
    var inicial:char = 'R'
    print(mensaje)
    print(inicial)
```

Los escapes válidos son `\n`, `\r`, `\t`, `\0`, `\\`, `\"` y `\'`.
Consulta [escapes](escapes.md), [concatenación](concatenation.md) y
[f-strings](f-strings.md).
