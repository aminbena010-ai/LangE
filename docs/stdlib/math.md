# Módulo estándar `math`

Importa `math` para trigonometría y utilidades numéricas:

```rivo
import math

fn main():
    print(math.square_root(81.0))
    print(math.factorial(5))
```

API exportada: `square_root`, `power`, `sine`, `cosine`, `tangent`, `ln`,
`log_10`, `exponential`, `pi`, `euler`, `round_to_int`, `floor_to_int`,
`ceil_to_int`, `is_integer`, `abs`, `abs_float`, `min`, `max`, `clamp`,
`is_even`, `is_odd`, `sign`, `integer_power`, `factorial`, `gcd`, `lcm`,
`average`, `celsius_to_fahrenheit`, `fahrenheit_to_celsius`. Comprueba en el
fuente `lib/math.ro` los tipos exactos antes de enlazar una API.
