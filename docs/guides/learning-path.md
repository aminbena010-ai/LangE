# Ruta de aprendizaje

1. Instala y compila un programa de [hola mundo](../introduction/hello-world.md).
2. Aprende [sintaxis e indentación](../language/syntax.md).
3. Practica [tipos](../types/overview.md), [variables](../variables/var.md) y
   [operadores](../operators/precedence.md).
4. Escribe [funciones](../functions/declaration.md) y usa
   [control de flujo](../control-flow/if-else.md).
5. Explora [listas](../collections/lists.md), [mapas](../collections/maps.md)
   y [módulos](../modules/import.md).
6. Consulta la [biblioteca estándar](../stdlib/text.md) y crea un
   [ejemplo completo](../examples/interactive-menu.md).

Ejecuta cada ejemplo con el compilador del checkout para familiarizarte con su
estado actual.
