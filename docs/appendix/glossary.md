# Glosario

| Término | Significado |
| --- | --- |
| AST | Árbol de sintaxis abstracta producido por el parser. |
| Bloque | Grupo de sentencias delimitado por indentación. |
| FFI | Interfaz para invocar funciones externas, aquí C. |
| Lexer | Fase que convierte caracteres en tokens. |
| Módulo | Archivo `.ro` importable. |
| Runtime | Biblioteca nativa enlazada con el ejecutable generado. |
| Tipo estático | Tipo comprobado durante la compilación. |
