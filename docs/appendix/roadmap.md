# Estado y evolución

Rivo está en desarrollo. Las funciones disponibles dependen del estado de
compilador, runtime y biblioteca en el checkout; las pruebas son la guía
práctica más fiable para verificar una característica.

```sh
sh tests/run_tests.sh
sh tests/runtime/run_tests.sh
```

No se publican aquí fechas ni promesas de características futuras. Para
decisiones vigentes, revisa el `CHANGELOG.md` y los cambios del repositorio.
