# Referencia de palabras clave

Declaraciones: `var`, `const`, `fn`, `return`, `external`. Control:
`if`, `elif`, `else`, `while`, `for`, `in`, `break`, `continue`, `pass`,
`try`, `catch`. Concurrencia: `async`, `await`. Módulos: `import`, `from`,
`as`. Literales: `true`, `false`, `null`. Tipos: `int`, `float`, `string`,
`bool`, `char`, `list`, `map`, `task`. Lógica: `and`, `or`, `not`.

```rivo
fn main():
    var listo:bool = true
    if listo:
        pass
```

Para una explicación temática, consulta [palabras clave](../language/keywords.md).
